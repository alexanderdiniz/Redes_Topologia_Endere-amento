CCNP · Módulo 11 Fundamentos de plataforma

11. Arquitetura do Cisco IOS

O Cisco IOS (Internetwork Operating System) é o sistema operacional proprietário que roda em roteadores, switches e appliances Cisco. Gerencia hardware, memória, protocolos e segurança.

◇ Funções principais

Routing & Switching

Encaminhamento via tabelas estáticas/dinâmicas (OSPF, EIGRP, BGP, RIP). Comutação L2/L3 (VLANs, STP, Trunking).

Segurança

ACLs, NAT, VPNs IPsec/SSL, inspeção de pacotes e AAA (RADIUS/TACACS+).

Quality of Service (QoS)

Filas, priorização (VoIP/vídeo), políticas de banda e controle de congestionamento.

Gerência e Monitoramento

CLI, SNMP, Syslog, NetFlow, telemetria em tempo real.

▤ Hierarquia de modos CLI

1. User EXEC

Router>

Monitoramento básico: ping, show version.

2. Privileged EXEC

Router#

enable eleva. Ver running-config, reload.

3. Global Config

Router(config)#

configure terminal acessa. Parâmetros globais.

4. Submodos

(config-if)#

config-if, config-router, config-line.

⌁ Variantes modernas

Cisco IOS XE

Control plane em kernel Linux, data plane em hardware. Catalyst e ISR.

Cisco NX-OS

Data center (Nexus). Modularidade e APIs programáveis (Python).

Cisco IOS XR

Service Providers. Arquitetura distribuída e microkernel.

▦ Simuladores e emuladores

Posso instalar o IOS direto no PC? Não — o IOS é compilado para ASICs específicos. Use simuladores/emuladores.

Packet Tracer

Gratuito

Simulador educacional oficial. Ideal para CCNA.

Cisco Modeling Labs

Oficial

Imagens reais (IOSv, XR, NX-OS) em KVM/VMware. CCNP/labs.

GNS3 / EVE-NG

Multi-vendor

Dynamips/IOU/QEMU. Topologias híbridas. Produção simulada.

12. Configuração Day 0 (SSH Seguro)

Sequência completa de provisionamento seguro: hostname, DNS desabilitado, logging synchronous, banner legal, RSA + SSHv2, linhas VTY restritas.

⚿ 1. Identificação, proteção e criptografia local

Define hostname, desabilita buscas DNS acidentais (no ip domain-lookup), configura senha via secret (hash) e evita logs interromperem digitação com logging synchronous.

IOSday0-basico.cfg
enable
configure terminal
hostname SW-CORE-01
no ip domain-lookup
enable secret SenhaForte123
line console 0
 password SenhaConsole123
 login
 logging synchronous
 exec-timeout 10 0
 exit
service password-encryption

△ 2. Aviso legal (banner MOTD)

IOSbanner.cfg
banner motd #Acesso restrito a administradores autorizados. Todas as atividades são monitoradas.#

▤ 3a. Interface em roteador

Portas vêm administratively down — exigem no shutdown.

IOS
interface gigabitethernet 0/0
 description Link_WAN_Operadora
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit

▤ 3b. Interface em switch L2 (SVI)

IP em interface vlan + ip default-gateway.

IOS
interface vlan 99
 description Gerencia_Switch
 ip address 192.168.99.10 255.255.255.0
 no shutdown
 exit
ip default-gateway 192.168.99.1

⚿ 4. SSH seguro + salvamento

Substitui Telnet por SSHv2 com chaves RSA 2048-bit, força SSH nas VTY e salva em NVRAM.

IOSday0-ssh.cfg
ip domain-name empresa.local
username admin privilege 15 secret SenhaAdminSSH123
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 15
 transport input ssh
 login local
 exec-timeout 10 0
 exit
end
copy running-config startup-config

13. NAT, DHCP e Automação Python

NAT PAT, DHCP server nativo e automação com Python Guest Shell (IOS XE).

⇌ NAT com Overload (PAT)

Compartilha um único IP público via tradução de portas TCP/UDP.

IOS
configure terminal
access-list 1 permit 192.168.100.0 0.0.0.255
ip nat inside source list 1 interface gigabitethernet 0/0 overload
interface gigabitethernet 0/1
 ip nat inside
 exit
interface gigabitethernet 0/0
 ip nat outside
 end

▷ Servidor DHCP nativo

Entrega IPs, máscara, gateway e DNS automaticamente.

IOS
configure terminal
ip dhcp excluded-address 192.168.100.1 192.168.100.10
ip dhcp pool REDE_LAN
 network 192.168.100.0 255.255.255.0
 default-router 192.168.100.1
 dns-server 8.8.8.8 1.1.1.1
 lease 7 0 0

14. Troubleshooting avançado: EPC & CPU

Embedded Packet Capture grava pacotes no buffer do roteador. Auditoria de CPU detecta loops e ataques.

✚ Embedded Packet Capture (EPC)

Captura tráfego diretamente no roteador com filtro ACL — sem port mirroring ou Wireshark externo.

IOSepc.cfg
! 1. Criar filtro ACL
ip access-list extended CAPTURE_ACL
 permit icmp any any
 exit
! 2. Configurar buffer
monitor capture MY_BUF buffer size 10 limit packet-count 1000
monitor capture MY_BUF match acl CAPTURE_ACL
monitor capture MY_BUF interface gigabitethernet 0/0 both
! 3. Iniciar e inspecionar
monitor capture MY_BUF start
monitor capture MY_BUF stop
show monitor capture MY_BUF buffer dump

▷ Auditoria de CPU

IOS
show processes cpu sorted 1min
show processes memory sorted
show platform resources
Dica: processo > 50% de CPU sustentado sem tráfego anormal indica loop de roteamento ou ataque.

15. OSPF Multi-Área, HSRP e QoS

Segmentação de domínio OSPF, redundância de gateway com HSRP e priorização de tráfego com QoS MQC.

⊗ OSPF Multi-Área

Divide domínios para conter flaps. Área 0 é obrigatória. ABR conecta áreas, ASBR injeta externas, Stub bloqueia LSAs tipo 5.

Área 0 (Backbone)

Núcleo obrigatório.

ABR

Conecta áreas e resume rotas.

ASBR / Stub

ASBR injeta externas; Stub bloqueia tipo 5.

IOSospf-multi-area.cfg
configure terminal
router ospf 1
 router-id 1.1.1.1
 network 10.0.0.0 0.0.0.3 area 0
 network 192.168.1.0 0.0.0.255 area 1
 area 1 stub

⇄ HSRP — Redundância de gateway

Agrupa roteadores em um Gateway Virtual. Active processa; Standby assume. preempt garante reassunção.

IOShsrp.cfg
! Primário (Active)
interface gigabitethernet 0/0
 ip address 192.168.10.2 255.255.255.0
 standby version 2
 standby 1 ip 192.168.10.254
 standby 1 priority 150
 standby 1 preempt
 standby 1 timers 1 3
! Secundário (Standby)
interface gigabitethernet 0/0
 ip address 192.168.10.3 255.255.255.0
 standby version 2
 standby 1 ip 192.168.10.254
 standby 1 priority 100
 standby 1 preempt

▷ QoS MQC

3 blocos: Class-Map (DSCP/ACL), Policy-Map (LLQ/banda), Service-Policy (aplica).

IOSqos-mqc.cfg
configure terminal
class-map match-any CLASSE-VOIP
 match ip dscp ef
policy-map POLITICA-CORPORATIVA
 class CLASSE-VOIP
  priority percent 25
 class class-default
  fair-queue
interface serial 0/0/0
 bandwidth 2048
 service-policy output POLITICA-CORPORATIVA

CCNP · Módulo 16 Engenharia de tráfego entre AS

16. BGP e Engenharia de Tráfego

Prefix-lists, route-maps, local-preference (saída), AS-Path prepending (entrada) e AS-Path ACLs com regex.

⊕ Local Preference + Prefix-List + Route-Map

Aumente o local-preference (padrão 100) para influenciar o tráfego de saída (egress).

BGPbgp-localpref.cfg
ip prefix-list BLOCO_PERMITIDO seq 10 permit 192.168.10.0/24
route-map POLITICA-ENTRADA permit 10
 match ip address prefix-list BLOCO_PERMITIDO
 set local-preference 300
router bgp 65001
 router-id 1.1.1.1
 no auto-summary
 neighbor 200.50.10.1 remote-as 65002
 neighbor 200.50.10.1 route-map POLITICA-ENTRADA in
 network 192.168.10.0 mask 255.255.255.0
end
clear ip bgp 200.50.10.1 soft in

⇄ Multi-Homing

BGP instala só a melhor rota. maximum-paths habilita ECMP entre operadoras.

BGP
router bgp 65001
 maximum-paths 2
 maximum-paths ibgp 2
 neighbor 200.50.10.1 remote-as 100
 neighbor 200.50.20.1 remote-as 200

△ AS-Path Prepending

Repete o próprio AS para tornar o caminho menos atrativo (entrada).

BGP
route-map PREPEND-ISP-B permit 10
 set as-path prepend 65001 65001 65001
router bgp 65001
 neighbor 200.50.20.1 route-map PREPEND-ISP-B out
end
clear ip bgp 200.50.20.1 soft out

▦ AS-Path ACLs com Regex

RegexSignificado
^Início da string AS-Path
$Fim da string (origem)
_Delimitador (espaço, início/fim)
.*Qualquer sequência de ASs
BGPas-path-acl.cfg
! Aceitar APENAS rotas originadas no AS 100
ip as-path access-list 1 permit ^100$
route-map FILTRA-CLIENTES permit 10
 match as-path 1
route-map FILTRA-CLIENTES deny 20
router bgp 65001
 neighbor 200.50.10.1 route-map FILTRA-CLIENTES in
! Bloquear qualquer rota via AS 6666
ip as-path access-list 2 deny _6666_
ip as-path access-list 2 permit .*

◈ IPv6

  • Notação: 8 grupos hexadecimais com :. Compressão: 0000 vira :: (uma vez).
  • Prefixo LAN: /64 — permite SLAAC.
  • Tipos: Unicast global (2000::/3), Link-local (fe80::/10), Multicast (ff00::/8), Loopback (::1).
  • Sem broadcast/NAT padrão: multicast e roteamento fim-a-fim.
IOSIPv6 config
ipv6 unicast-routing
interface gigabitethernet 0/0
